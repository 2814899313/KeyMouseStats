# v4 页面视觉改版（2026-11-23）

目标：把 9 页首版从「能看」升级为有统一美术语言、有信息层级、有明细与洞察的面板。

## 设计基座

新增 `src/Kms.App/Pages/PageKit.cs`，所有页面共用：

- **页头**：小号强调色 kicker + 30px 标题 + 12px 副标题 + 右侧日期/动作
- **卡片**：Raised→Card 渐变、1px 边框、可主题化圆角、轻投影、可选 hover 描边
- **指标卡**：kicker / 32px 大数 / 单位胶囊 / 说明 / 7 点迷你面积折线
- **区块**：左侧 3px 强调条 + 标题 + 提示 + 分隔线 + 右上角标签
- **胶囊**：筛选、状态、图例；13 套主题自动取色
- **排行**：序号徽章、键帽/名称、渐变比例条、右侧值 + 副值
- **环图**：`Donut` 原语 + 中心大数 + 图例
- **活动带**：24 格逐小时强度
- **数字/时长/距离**：统一格式化

## 外壳

- 252px 侧栏：品牌 K 渐变块、9 个图标导航、活动指示条、数字快捷键
- 13 个主题色板（点击即时切换并写入 `theme_id`）
- 左下 LIVE 状态卡：采集状态、数据源、天数、实时绿点
- 背景柔光层：Accent / Cyan / Purple 三个低透明度椭圆
- 主窗口聚焦后支持 `Ctrl+1..9`、`Esc`

## 布局密度（对齐 v3）

v3 基准画布是 **1072×724 @96dpi**，侧栏 176、内容区 896。v4 保留同一密度思路，而不是把每页做成竖向大卡片流：

- 页头压缩到约 55 DIP：kicker 9 / 标题 26 / 副标题 11
- 页面边距 20/16，区块间距 10，卡片内边距 12–14
- 汇总从「4 张 160px 指标卡」改为 50px 高的 `StatStrip`（趋势/小时/按键/应用/洞察/字符/热区）
- 概览保留 4 张紧凑指标卡，主体改为 2×2 面板（7 日节奏 / 输入构成 / 应用 Top / 今日高光）
- 趋势页：统计条 → 筛选 → 曲线 + 逐日明细 → 工作日 + 洞察，一屏基本可见
- 应用页：统计条 → 筛选 → 表格 + 时长构成，表格行高压缩，名称不再被路径挤成 4 个字
- 小时页：统计条 → 筛选 → 24 柱 + 小时详情 → Top 小时 + 活动带
- 侧栏从 252 收窄到 232 DIP，给内容区多留 20px
- 不再每页都使用「大 Hero + 四张同构卡片」模板；各页按 v3 的信息优先级组织
