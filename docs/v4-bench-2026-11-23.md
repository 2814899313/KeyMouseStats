## 结论

- 静态页与强制重绘稳定在 120 fps 预算内（P99 5.41 ms < 8.33 ms）。
- **beta.2 同源开发构建**：4,118 帧、平均 4.321 ms、P99 5.411 ms、目标 120 fps 未降级；字符页切换时有一次 126 ms 构建尖峰，但 P99 仍低于 8.33 ms。
- 页面切换会触发一次性 30–126 ms 的构建/布局峰值，切换后立即恢复；不影响持续动画。
- 本机未触发 `FrameBudget` 降级；弱机/多屏/4K 仍建议用同一命令复测。

复跑：

```bat
dotnet src\Kms.App\bin\Release\net10.0-windows\Kms.App.dll --bench-ui
type %TEMP%\kms-v4-bench.json
```

> 该命令不会启动采集钩子，但仍会短暂显示主窗；24h 对拍期间可安全运行。
