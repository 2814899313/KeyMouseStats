## 1. 24h v3 / v4 计数对拍

### 前置

- [ ] 用 `tools\start-24h-compare.bat` 同时启动 v3 与 v4（会检查两个 exe 是否存在），记录启动时间。
- [ ] v3 与 v4 同时运行，均使用真实钩子；v4 只读 v3 的 `stats.txt`，不写 v3 目录。
- [ ] 记录开始时间、v3 数据目录、v4 数据目录。
- [ ] 期间正常使用键鼠，至少覆盖：打字、浏览、游戏/高 APM、午休空闲、跨零点。

### 结束采样

- [ ] 关闭游戏/高负载程序，让两边完成一次保存（v4 可正常退出触发保存；不要强杀）。
- [ ] 复制两边 `stats.txt` 到独立证据目录（不要直接改原文件）。
- [ ] 记录结束时间与实际时长（应 ≥ 24h）。

### 对拍口径

| 指标 | 口径 | 容差 |
|---|---|---|
| 击键 | 当日 `keys` 与区间累计 | 计数应为整数相等；若因启动顺序差几次，记录差值与时点 |
| 点击 | 左/右/中/侧键与总点击 | 同上 |
| 滚轮 | 上/下累计 | 同上 |
| 移动距离 | `moveMeters` / 原始像素 | 浮点 `1e-9`（同一输入序列） |
| 活跃秒 | 会话并集 | 秒级差值需能由启动/退出边界解释 |
| APM 峰值 | 当日峰值 | 整数相等；分钟边界需一致 |
| 应用时长 | 前台归因 | Top 应用与总时长可解释 |

- [ ] 用 `Kms.Oracle` / 文本 dumper 对同一份输入生成期望值，确认浮点 `1e-9`。
- [ ] 把差值写入下方证据表；**任何无法解释的差值都算未通过**。

参考命令（v3 Oracle 需先按 `tools/oracle/README.md` 编译，约 2 分钟）：

```bat

```

`fc` 只做首轮定位；浮点行允许 `1e-9` 相对误差，最后一位表示差异需人工确认，不能直接判失败。

## 2. 悬浮组：透明 / 穿透 / 焦点

先按 [`tools/transparent-spike/README.md`](../tools/transparent-spike/README.md) 的 spike 清单确认平台能力，再验产品窗。

### Widget（悬浮窗）

- [ ] 透明背景无黑底、无白边；圆角外区域可点穿。
- [ ] 卡片内可拖动；右键切模式；滚轮切模式；不抢游戏焦点。
- [ ] 悬停显示 APM/活跃/段数；移出后恢复。
- [ ] 跨屏拖动不变形；缩放 150%/200% 下文字不糊、不裁切。

### FocusPill（专注胶囊）

- [ ] 常态/展开切换正常；点击不夺走当前前台窗口焦点。
- [ ] 呼吸点连续，无闪烁/跳变；展开后内容不溢出。
- [ ] 置顶后仍可点穿不需要交互的区域。

### GameHud

- [ ] 默认点击穿透，游戏内鼠标可穿过 HUD。
- [ ] 托盘「编辑 Game HUD」进入编辑态后可拖动；右键退出编辑。
- [ ] 退出编辑后位置写入 `hud_x/hud_y`，重启后位置保持。
- [ ] 多屏/负坐标屏位置被夹回可见区域。

### FocusBreakToast

- [ ] 从底部出现，15 秒自动消失；三按钮命中准确。
- [ ] 不抢焦点；点击按钮后不再阻塞输入。

## 4. 整窗 120 fps

目标：主面板静态帧 ≤ 2 ms，动画帧 ≤ 8.3 ms（120 fps）；弱机按 `Motion.FrameInterval` 降级。

- [ ] 主面板 9 页逐页停留 10 s，记录平均帧时间与 p99。
- [ ] 触发页面切换、侧栏悬停、图表重绘，记录最大帧时间。
- [ ] Widget 呼吸点、FocusPill 脉冲、HUD 1 s 刷新同时开启，重复测量。
- [ ] 缩放 150%/200% 各测一次。
- [ ] 弱机降级：人为限制到 60/30 fps 时无累积延迟、无跳帧。

建议工具：PresentMon 或 GPU 厂商帧时间工具；记录 CSV/截图作为证据。

### 本机自动化结果（2026-11-23 / beta.2）

`Kms.App --bench-ui` 在 1.5× 缩放、强制重绘 18 秒下：

- 4,118 帧，平均 **4.321 ms**，P95 4.812 ms，P99 **5.411 ms**，目标 120 fps 未降级。
- 发布候选 exe 复跑前的同源开发构建结果；beta.1 的 4.301 ms / P99 5.336 ms 作为对照。
- 页面切换峰值 30–126 ms（一次性构建），切换后恢复。
- 详见 [`v4-bench-2026-11-23.md`](v4-bench-2026-11-23.md)。
