这版为什么更像“数据面板”

默认只读：设备名和大数字是主角，编辑/换新/设备信息全部按需展开；轨道、胶囊、键帽改成低透明度层次。

点「编辑」看输入浮层；点「···」看换新/设备信息
100/150/175% 与紧凑高度可切换
01

默认只读，不再摊开表单

卡片平时只展示设备名、最高磨损键/左右微动和一条细轨道。编辑别名、额定寿命才打开轻量浮层，换新和设备信息收进「···」。

02

控件软化

不再使用灰底输入框+亮边按钮。输入只在浮层出现；胶囊、键帽、按钮、轨道统一为低透明度底色 + 极淡描边，减少“硬塑料块”感。

03

信息分层

默认只留主角数字；起始日期、额定寿命、中/侧键计数降为弱化小字。HID 路径移入「设备信息」，预警收敛成单个状态胶囊。

04

数字排版

大数字用 36–38px / 700 字重 / tabular-nums，百分比符号缩小；标题用 Segoe UI Variable 与雅黑 UI，减少松散字距。

想请你重点看：1）键盘用「最高磨损键」做主角，鼠标用左右两个大数字，这种主视觉是否成立；2）编辑浮层是否比常驻表单更舒服；3）「···」菜单收纳换新/设备信息是否够好找；4）7 天火花线是加分还是多余；5）紧凑模式下是否还保留足够呼吸感。
实现映射不变：键盘/鼠标多档案、RawInput 设备路由、legacy 归并、主设备镜像旧格式；这次先定视觉与交互。
