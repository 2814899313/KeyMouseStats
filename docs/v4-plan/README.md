本方案已把待定项收成默认取值（主方案 §13），因此**不依赖任何额外确认即可施工**。仅有两条环境事实需要知道：

| 项 | 现状 | 说明 |
|---|---|---|
| .NET SDK | 本机为 **8.0.425**（.NET 8 LTS 已于 2026-11-10 到期） | 目标框架是 .NET 10 LTS，需要在动工时升级 SDK；这是环境准备，不是方案缺口 |

## 三份最容易踩坑的结论（先看这三条）

1. **主题是 13 套不是 12 套**，且 `radius` 有 0 / 2 / 18 这种刻意值（`01-ui-spec.md` §2）。
2. **`PathGradientBrush.SetSigmaBellShape` 在 Skia 无等价物**，点击热区的云状效果必须重做（`02-api-mapping.md` §2）。
3. **24 条统计口径里任何一条搬错，v4 的数字就和 v3 不一样**（`03-data-spec.md` §4）。
