# 4.0.0-beta.1 · 功能完整候选

> 这是 v4 重写的功能完整候选版，**不是**可替代 v3 的正式版。
> 24h 对拍、真机 DPI/穿透/剪贴板验收尚未关闭；正式 4.0.0 需在这些项通过后再发。
> 版本号唯一来源：`Directory.Build.props`；v3 仍为 `Version.cs` 的 3.4.1。

## 相对 alpha.1 的变化

- **总览按 V3 重做**：面包屑、8 张 88px KPI（P50/P90）、鼠标/键盘分布环、累计 Top5、洞察条、导出 CSV、实时时钟。
- **外壳按 V3 重做**：侧栏导航/蓝色选中胶囊/主题区/版本状态；无边框窗口 + 自定义最大化/关闭按钮。
- **V3 皮肤恢复**：9 套美术主题按页面加载 V3 原画背景，卡片半透明；侧栏 `+` 打开皮肤画廊，自动读取 V3 `custom-themes.json` 中的自定义壁纸，并按背景/强调/文字色生成完整调色板。
- **主题选择修复**：优先 `theme_id`，回退 V3 `art_theme`，不再默认丢回午夜蓝。
- **心流/热区**：Deep/常规/碎片分段、点击拖动时光机；热区网格/云状热斑切换。
- **悬浮组**：Widget 目标模式、FocusPill 180ms 展开动画 + 120fps 呼吸点、HUD 编辑持久化、托盘置顶。
- **报表/导出**：5 页报表图表化 + 战报自适应高度 + 剪贴板摘要/战报图 + 战报脱敏。
- **性能/验收**：`--bench-ui` 120fps 基准、`--selfcheck-ui` 悬浮窗样式自检；950 项测试全绿。

## 验收基线

- 950 项测试：Core 187 / Input 191 / Storage 35 / Golden 531 / Architecture 6。
- 45 张运行时基线：9 页 + Hours 96/144/192 + Widget 4×3 主题 + HUD/Toast/胶囊 + Text/Keys 长页 + 报表 5 页 + 整窗外壳/美术皮肤。
- `--bench-ui`：本机 150% 缩放、9 页强制重绘，P99 **5.336 ms**，目标 120 fps 未降级。
- `--selfcheck-ui`：Widget/Pill/HUD/Toast 的 `TOOLWINDOW`/`NOACTIVATE`、HUD `TRANSPARENT` 全部通过。
- 战报 3×（4320×9156）渲染约 **119 ms**。
- 完整清单与证据表见 [`docs/v4-acceptance.md`](../v4-acceptance.md)。

## 已知缺口（4.0.0 正式版前必须关闭）

- 24 小时 v3/v4 计数对拍尚未形成连续有效窗口；当前只能算 beta。
- 真机 200%/多屏跨屏、人工鼠标穿透/焦点、微信/QQ 剪贴板粘贴尚未验收。
- 88.6 MB 单文件首次启动解包/杀软扫描需要干净目录复测。
- 双轨自动打包与发布审计（v3/v4 同版本号、哈希、回滚）仍待收口。
- v4 只在首启导入 v3 数据；之后 v3 新增记录不会自动同步（避免双写/重复计数）。
