# KeyMouseStats 1.7.3

## 按键时长

新增「按键时长」页：按住时长的 8 档直方图、每键平均时长排行，以及覆盖率与丢弃样本数。

时长取首次按下到抬起的间隔，用单调时钟测量。系统的自动重复不会重置起点；超过 60 秒的按住视为挂机或丢失抬起；锁屏、休眠与退出时未抬起的按键同样丢弃。这些都会计入「丢弃」而不是混进平均值。

关于这一页要诚实说两件事：**按住时长不是按压力度**——普通键盘没有压力感应，它只是按住的时间；**丢失抬起是常态**（Alt+Tab、Win 键、游戏吞键都会），所以页面必须显示覆盖率，覆盖率低时结论要谨慎。

## 应用 × 键位

「应用键位」页给出应用行 × 六类键位分组（移动 / 技能栏 / 交互 / 功能 / 文字及其他 / 未归位）的构成热图与明细，用来回答「哪个应用最吃 WASD」这类问题。

按键在按下时归因到当时的前台进程。每天只保存击键最多的 12 个应用，其余并入「其他应用汇总」——逐键 × 应用的完整矩阵会撑爆文本格式。未归因的击键单列，不按比例分摊。这一页只描述按键构成，不推断应用用途。

## 数据保留与归档

以前保留期硬编码 365 天，超期的日记录在每次保存时被直接删除，用户既不会收到提示也没有选择权。现在：

- 保留期可配置（30—3650 天，或永久保留），入口在数据管理对话框。
- 超期数据先按月度折进归档（合计、活跃时长、应用 Top 16 的击键数），再移除明细。
- 归档不参与任何日级统计，所以现有页面的数字不会被它影响。

## 数据格式 v11

新增可选字段 `hold_v1`、`hold_key_v1`、`app_keys_v1`、`archive_v1`、`keep_days`，并写入 `format` 版本标记。v10 旧文件照常读取，缺少的维度显示「从 1.7.3 起采集」，不反推、不补零。文件由更新版本写入时，数据管理对话框会提示。

发版流程本身也简化了：版本号现在只有一个来源，这次只改了一处。
