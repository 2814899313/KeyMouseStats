# KeyMouseStats 2.3.2

2.3.2 为小组件存储页增加每日占用增量。

## 存储页

- 在总占用右侧增加「今日 +x MB」与「昨日 +x MB」。
- 首次升级没有历史快照时，会根据现有 `backup` 与 `日报` 文件的日期回填最近两天，避免先显示空白。
- 每日快照保存到数据目录的 `storage-history.txt`，只保留最近 90 天，体积可忽略。
- 启动时后台记录一次快照；打开存储页时也会刷新当天记录。

## 注意

这里显示的是**磁盘存储增长**，不是内存 RAM 占用。历史备份每天会新增完整快照，因此日增量通常明显高于核心统计本身的增长。

## 升级

直接覆盖 `KeyMouseStats.exe`。没有改变统计数据格式；新增的存储历史文件不影响旧数据。
