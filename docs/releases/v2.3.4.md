# KeyMouseStats 2.3.4

2.3.4 收口日报页的状态、应用名、底栏和字符卡。

## 日报

- 日报页不再显示全局「今日累积中」徽章；所查看日期的状态只由卡片内的「已结束 / 进行中」表达。
- 应用排行使用友好应用名和应用图标，不再直接显示 `msedge.exe`、`ChatGPT.exe` 之类的进程名。
- 底栏改为「✓ 已归档至本地日报目录」，点击直接打开日报目录；不再打印会被截断的绝对路径。
- 「保存 Markdown」改为蓝色实心主按钮，「复制简报」保持次级按钮。
- 时间分布所有小时都有极淡底槽，空时段不会破坏横轴底座。
- 下栏卡片改为「字符构成」，主数字显示平均每次上屏字数，与顶部「上屏字数」互补。

## 升级

直接覆盖 `KeyMouseStats.exe`，不改变数据格式。
