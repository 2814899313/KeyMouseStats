# KeyMouseStats 2.3.0

2.3.0 把统计报告的能力正式迁入主面板，并完成多屏、详情性能和主题交互收口。统计报告入口不再作为日常导航出现。

## 主面板

- 总览：击键与有效使用时长卡片下方加入过去 30 天 P50 / P90 基线；KPI 卡片可打开输入画像或实时状态详情。
- 趋势：增加「对比上期」；按小时支持主题内联多曲线菜单；图表标题旁可直接查看分布详情。
- 时段分布：指标、形态、时间范围拆成三组独立分段控件；形态组带图标；连续段强度视图提供当前时间游标、发光时间线和专注段胶囊卡片。
- 按键排行：等宽键帽、频次条与占比整合、Top 11–20 固定列、输入画像摘要；按住时长支持按住趋势详情。
- 应用统计：点击应用行打开详情抽屉，包含应用 × 时段、操作构成、最近会话归因；类别卡只展示有数据的分类，未分类提供「去分类」入口；详情头部使用应用名与分类，不再裸露完整路径。
- 点击热区：增加鼠标动作入口，展示快速移动、急转、方向占比和移动后点击。
- 使用洞察：保留年度日历、会话时间轴、七日节奏，报告入口退役。
- 日报、字符内容、点击热区继续保留原有独立能力。

## 统计报告入口退役

统计报告不再作为独立窗口维护，原有能力已迁入主面板：

- 输入习惯、实时状态：总览卡片详情
- 分布：趋势页「分布」入口
- 鼠标动作：点击热区页「鼠标动作」入口
- 按住时长趋势：按键排行「按住趋势」入口
- 应用时段、应用操作、会话应用：应用统计行详情

旧的报告导航、报告入口和「在报告中查看」按钮已移除。报告窗口附带的 PNG / HTML / 打印导出随入口一并退役，主面板保留 CSV 导出。

## 多屏与性能

- 跨显示器拖动时按当前屏幕工作区重新适配尺寸和位置，避免小屏或不同 DPI 下被裁切。
- 详情抽屉使用按 DPI 的位图缓存；静态详情不再每秒重绘，实时详情约 1.2 秒刷新一次。
- 详情打开时跳过后台页面绘制，关闭详情或点击左侧导航即可返回。

## 升级

直接覆盖 `KeyMouseStats.exe`。2.3.0 没有改变统计数据格式，2.2.0 / 2.1.0 / 2.0.7 的历史记录、分类和设置会原样保留。
