# KeyMouseStats 3.0.0

3.0.0 是 v3 数据底座、界面体系与分析闭环三个里程碑的正式收官版本。单文件分发、全部资源内嵌；历史 v2 文本存档可无损迁移。

## 数据底座

- 原生 SQLite 事件流（13 张表）与阴影双写；崩溃自愈、零阻塞主线程。
- v2 `stats.txt` → v3 `kmstats.db` 迁移：SHA256 冷备份 + manifest 逐字节复核 + 四项守恒断言。
- 迁移幂等：`migration_log.content_sha256` + `INSERT OR IGNORE`；`.kms` 跨端增量合并使用同一套主键账本。
- 三通道点击热区与十类应用分类服务。

## 界面体系

- 全站 9 页弹性栅格：`Cw` 横向铺满、`PageBottom` 纵向收口，1072×724 与 2K 下均无卡片越界。
- 多屏 DPI：字体按逻辑像素只缩放一次；摆位后重新采样 `_s`；`MinimumSize` 受当前显示器工作区夹紧。
- 悬浮小窗：右侧「鼠标路程」与底部「最近 5 分钟 APM」保留安全内边距，圆角背景实心填充。
- 字符内容「输出应用」升级为特征词：2–4 字词组优先、虚词过滤、实词单字兜底；胶囊按卡片宽度动态收敛，悬停展示 Top 5 词组与单字画像。
- 大屏收口：总览分布环随卡片放大、组合键排行无尾巴时改为整栏画像、年度日历下方补区间摘要与月度活跃、日报字符构成补明细与输入节奏。

## 分析与生态

- 深度心流量化：5 分钟滑窗三态、专注分 0–100、最长心流连击。
- 上下文切换损耗、全天工作轨迹时光机、健康节律守护、隐私打码战报长图。
- 日报 / 周报 / 月报长图导出。

## 性能

- 换页不再捕获整页位图快照:所有 DPI / 分辨率下直接纯矢量重绘,过渡帧与最终页逐像素一致,彻底消除 2K 双折线与矩形色差残影。专项回归见 `tests/TransitionGhostTests.cs`。
- 动画帧改为整窗失效重绘,避免双缓冲下只清局部 clip 导致上一帧折线残留。
- 换页/筛选加入 160ms 全窗柔光淡入;动画帧间隔收紧到实测耗时 ×1.25,2K 下切换更顺滑。
- 键位热力与报告帮助浮层同步移除旧板/背景位图交叉淡入,改为当前帧直接绘制。
- 悬停状态签名去抖、空闲分步预热、按键排行/应用图标缓存。

## 兼容性

- 数据格式 v13 保持向后兼容；清爽版继续满足 ≤2 MiB 与 0 内嵌托管资源。
- 版本号单一来源：`Version.cs`、程序集 File/ProductVersion、`CHANGELOG.md` 与本文件统一为 3.0.0 / 3.0.0.0。
