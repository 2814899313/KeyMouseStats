# KeyMouseStats 2.3.11

2.3.11 修掉一类会破坏历史数据的事故：测试与预览进程曾经把夹具数据写进用户真实数据文件。

## 持久化护栏

- 只有产品主进程（或显式重定向了数据目录的测试）才允许保存；测试、预览、渲染进程的 `Save()` / `SaveAsync()` 一律不启动保存流程。
- 同一道门禁也覆盖日报、存储历史与每日备份，避免测试夹具出现在用户目录里。
- 回归测试用「保存序号是否变化」判定，不依赖文件系统权限；并复现了「80 天夹具 + 打开/关闭面板」的真实事故路径。

## 读取失败不再覆盖

- `stats.txt` 存在却读不出来，或文件里有 `[day=]` 却解析不出任何日记录时，标记读取失败并拒绝后续保存，同时往诊断日志写一行。
- 一次成功的读取会清除该标记，不会把程序永久锁在只读状态。

## 其他

- 修复被整文件破坏（字母 e 变成 l）的 `tests/RenderDashboard.cs`，预览渲染重新可用。
- 版本号 2.3.11 / 2.3.11.0。

只影响数据写入路径，不改变采集格式与界面。

## 日报目录

- 日报目录改为跟随数据目录；重定向过的渲染测试不会再把自己的夹具日报写进用户的 `%APPDATA%\键鼠统计\日报`。
- 恢复过程中被夹具写成「无数据」的 11-02 / 11-10 / 11-11 / 11-14 日报已按真实记录重新生成。
