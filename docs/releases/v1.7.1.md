# KeyMouseStats 1.7.1

## 数据管理

从托盘菜单「数据管理」进入，四件事集中在一个对话框里：

- **备份**：每天首次启动自动留一份带日期的备份，默认保留 7 份，可按需调整；也可以随时手动备份或打开数据目录。
- **导出**：生成带 SHA-256 校验和的单文件。
- **导入 / 多机合并**：导入前先校验，校验不通过不会写入任何数据；写入前显示冲突预览（多少天与现有记录重叠、导入的击键总量）。同一天两边都有记录时，可选「保留击键更多的一份」（不会重复计数，两台机器同时使用时可能低估）或「两份相加」（分开使用时正确，同时使用时可能重复计数）。
- **校验**：逐日检查活跃秒、空闲秒、小时分桶、逐键计数、段时长、应用时长与交叉观测等不变量，给出错误与警告清单。

合并后「累计总数」是近似值，日记录本身按策略精确合并，界面会明确标注这一点。

## 呈现交互

- **拖拽刷选**：在区间回顾的逐日柱状图上拖出一段，松开即切换为自定义区间，其余指标随区间重算。
- **对比区间**：区间回顾不再只能对比「紧随其前」，可以选择去年同期或自定义区间，任意两段并排比较。
- **网页导出**：报告头部的「导出」改为下拉菜单，新增自包含 HTML——图表以 base64 内嵌、明细以表格呈现、不含脚本、离线可开，适合存档或分享。

数据格式仍为 v10（新增可选 `backup_keep` 设置），不迁移或改写历史统计。
