# KeyMouseStats 1.7.0

## 区间分析

新增的处理层把区间口径、聚合、分布、趋势与对比收敛到一处。此前各页各自计算，口径需要人工对齐；现在终点、缺失日、日均分母和「基准不足」的处理只有一份实现，`PersonalStats` 与 `WeekAnalysis` 也改为委托它。

同时补上两类过去没有的统计：分布（P10/P50/P90、标准差、变异系数、直方图分箱）与趋势（按实际日期间隔的线性斜率、拟合优度、按星期去均值的周期偏移）。

## 区间回顾

「本周回顾」升级为「区间回顾」。报告顶部可以选择近 7 天、近 30 天、本月、上月、本季度、今年或自定义区间，页面把所选区间与紧随其前的等长区间对比。由于两期有效天数可能不同，页面同时给出合计变化与日均变化，并在覆盖列标出各自的有效天数。

## 分布

新增「分布」页：三行箱线图分别展示逐日击键、连续段时长与单应用单日时长的分布，下方是逐日击键的直方图。用分布替代单点均值，可以看出波动和长尾，而不是被平均值掩盖。样本少时自动减少分箱；样本完全相同时只画一个标记，不伪造差异。

报告导航同步重排为四组：时间与节奏、应用使用、输入方式、周期与分布。

数据格式仍为 v10，不迁移或改写历史统计。
