# KeyMouseStats 1.7.2

## 每日目标

可以给每一天设一个目标——按击键数或按活跃时长，随时可以关掉。达成时当天只提示一次，不会反复打扰。

小组件的窗口尺寸没有变，单击会在 **今日 / 目标 / 累计** 三种模式间循环。目标模式显示进度环、已用与目标、以及还差多少。区间回顾报告新增「目标达成天数」与「连续达成天数」两行；缺失日跳过，不打断连续计数。

## 提醒

- **连续使用提醒**：默认关闭。可以设置超过多少分钟提醒一次，以及同一提醒的冷却时间。基于「连续活跃段」，与空闲阈值是两个独立设置，改提醒不会改统计口径。
- **免打扰**：前台窗口占满整个屏幕（游戏、全屏视频）时自动抑制提醒，不打断你。
- **每日摘要**：到设定时间后提示一次今日概况，同样只提示一次。

三者都可以在托盘菜单的「目标 / 提醒」里开关，默认全部关闭。

## 工程

版本号改为单一来源 `Version.cs`——程序集属性、界面文字和 CI 校验都读它，发版只需改一处。剩余 6 个测试也改用 `Store.DataDirectory` 重定向数据目录，不再用反射改写私有字段。

数据格式仍为 v10（新增可选 `wellbeing_v1` 设置），不迁移或改写历史统计。
