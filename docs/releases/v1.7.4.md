# KeyMouseStats 1.7.4

这一版不谈新指标，只解决一件事：**面板和报告之间的往返**。

## 报告 → 面板：在面板中查看

以前在报告里看到「上周三移动距离偏低」这类结论，想回面板细看，只能关掉报告，再自己切页、切区间、翻到那天。

现在报告标题栏多了一个「在面板中查看」：点一下，面板会带着报告当前的日期与区间一起打开，并跳到对应页。

## 面板 → 报告：在报告中查看

反过来，面板底部新增「在报告中查看」。它把当前页与当前筛选原样交给报告：

- 趋势页 → 区间回顾；时段页 → 时段分布；按键页 → 按键排行；应用页 → 应用时间。
- 当前选中的时间范围（今日 / 近 7 天 / 近 30 天 / 近 90 天）一并带过去。

报告打开时不再把区间下拉框复位成默认值，而是沿用传进来的区间；如果你在报告里手动改过筛选，之后以下拉框为准。

## 面板补齐 1.7.3 的新维度

1.7.3 的按键时长与应用 × 键位此前只在报告里能看。这一版把它们补进面板：

- **按键页** 新增「按住时长」模式：区间内每键平均按住时长排行与覆盖率，与报告页共用同一套汇总口径。
- **应用页** 新增「键位构成」模式：应用行 × 六类键位分组（移动 / 技能栏 / 交互 / 功能 / 文字及其他 / 未归位）的占比，按当前时间范围汇总。

两个模式都只是切换视图，不改变任何数据口径。缺少该维度的旧记录显示「该区间无此维度」——不补零、不反推，这一点和 1.7.3 保持一致。

## 升级

直接覆盖 `KeyMouseStats.exe` 即可，数据格式仍为 v11，1.7.3 的数据文件原样可用。
