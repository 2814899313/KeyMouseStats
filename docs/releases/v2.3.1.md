# KeyMouseStats 2.3.1

2.3.1 修复开机自启动计划任务的权限问题。

## 自启修复

- 程序清单为 `requireAdministrator`，而计划任务之前使用受限权限运行，导致登录触发失败，任务结果为 `0x800702E4`（需要提升权限）。
- 计划任务改为最高权限运行，与程序清单一致；由任务计划程序在登录时启动，不额外弹 UAC。
- COM 注册失败时的 `schtasks` 兜底也改为 `/RL HIGHEST`。
- 启动时的 `AutoStart.Sync()` 会把旧任务路径更新到当前 exe，并重新注册权限级别。

## 升级

直接覆盖并重启一次。已经存在的旧任务会在首次以新版本启动时自动更新路径和权限；如果仍未生效，在托盘菜单里关闭再打开一次「开机自启」即可强制重注册。
