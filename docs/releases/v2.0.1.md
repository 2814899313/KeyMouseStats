# KeyMouseStats 2.0.1

一个小版本:字符内容页多了一个统计类目 **不同字符**,顺带把版本号规则固化下来。

## 不同字符

字符内容页第一行从四张卡变成五张,第五张是 **不同字符**:

| 项 | 含义 |
|---|---|
| 主数字 | 区间内**去重后**的字符种类数,按 Unicode 码点算(代理对算一种) |
| 副标 | 「汉字 N 种」:排除标点、字母、数字后的汉字种类 |

和「区间上屏字数」的区别要说清楚:**那是次数,这是种类**。同一天打 100 个「的」只算 1 种;这个数字回答「我今天用了多少种不同的字」,适合看写作的丰富度——只写代码的时候它会很低,写文档、聊天的时候明显变高。

日报的字符块和导出的 Markdown 也同步加了这一项:

```markdown
- 上屏 766 字 / 276 次，平均 2.8 字/次
- 不同字符 156 种（其中汉字 132 种）
- 构成：汉字 90% · 标点 4% · 字母数字 6%
```

## 版本号规则

从这一版开始,每次交付自动升补丁位(2.0.0 → 2.0.1):

1. 补丁位 +1:一般改动(新统计项、修 bug、调界面);
2. 次版本位 +1:架构或使用方式变了(2.0 → 2.1);
3. 主版本位:不兼容的大改。

三条同步要求写在 `Version.cs` 头部:改版本号、补 `CHANGELOG.md` 顶部一节、在 `docs/releases/` 新建同版本号的说明;CI 的 `release.yml` 会校验 tag 与 `FileVersion` 一致。
