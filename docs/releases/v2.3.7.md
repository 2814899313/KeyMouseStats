# KeyMouseStats 2.3.7

2.3.7 优化字符内容页的两个新视图。

## 输入效率

- 左栏首选率增加绿色首选直出 / 琥珀翻页选词的分段胶囊条。
- 图例改为「首选直出 N 条 / 翻页选词 N 条」，不再铺枚举文案。
- 右栏平均码长增加 1.5–4.0 键/字标尺，标出全拼均值 3.1，并用蓝色光点标记当前值。
- 底部说明改为自然语言：基于 N 条拼音上屏，不含纯英文与标点直出。

## 输出应用

- 改为四列网格：应用图标与名称、字数占比进度条、字数与占比、汉字高频徽章。
- 每个应用最多三个高频徽章，自动过滤纯标点。
- 移除底部重复说明，来源说明收进标题旁 ⓘ。
- 应用图标支持从当前同名进程解析完整路径，失败时用首字母图标兜底。

## 兼容性

只影响展示；数据格式与采集方式不变。
