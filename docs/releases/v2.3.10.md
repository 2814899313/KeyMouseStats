# KeyMouseStats 2.3.10

2.3.10 修复日统计派生桶与全局累计不一致的问题。

## 数据自检

- 启动时检查每日 `keys` 与小时/按键桶、`clicks` 与小时点击桶是否一致。
- 不一致时以日总数为准等比校准，并写入诊断日志。
- 同日重复的 `[day=]` 节只取第一节，避免标量与派生桶混算。
- 从逐日记录和月归档重建 `total_*`，修正总览累计为零或落后。

## 键盘与鼠标

- 今日缺失的鼠标按钮明细按常态补到左键，历史日不强行改写。
- 键盘钩子本身未改动；页面总数将统一到日记录。

## 数据安全

- 修复前已把 `stats.txt`、备份和诊断文件完整复制到
  `%APPDATA%\键鼠统计\backup\repair-20261114-224335\`。
- 修复仅调整派生桶，不删除原始历史日期。
