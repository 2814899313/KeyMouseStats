# KeyMouseStats 3.1.0

3.1.0 开启「视觉沉浸与自定义皮肤生态」阶段。新增本地壁纸皮肤引擎与 AI 专属生图提示词模板器，继续保持单文件分发、零第三方依赖、清爽版 ≤ 2 MiB 与 0 内嵌托管资源。

## 自定义壁纸皮肤

- 数据目录新增 `themes/`：保存原图、240×135 缩略图、1920×1080 主背景缓存与轻量配置 `custom-themes.json`。
- 支持导入本地 `.png` / `.jpg` / `.jpeg` / `.bmp`；导入、解码、缩放缓存与主色提取都在后台线程完成。
- 48×48 像素采样提取暗调主色与高对比强调色，并自动派生完整的 `ArtTheme`：背景、卡片、抬升面、线条、正文、弱化文字、强调色、五种辅助色、侧栏与强调色前景。
- 色彩护栏：主背景强制压入暗调，白色正文对比度 ≥ 13.5:1；强调色对背景 ≥ 4.5:1；弱化文字 ≥ 4.5:1；卡片与背景保持可辨识亮度差。
- 渲染管线：全画布 Cover 裁切 → 0.86 基础压暗 → 左侧 / 顶部 / 底部线性羽化 → 可调暗度遮罩。默认 70%，支持 50%–85%、步进 5%；即使 50% 遮罩落在纯白画面，白色标题仍保持 ≥ 4.5:1。
- **视口合成背景**：按 `skin + 物理宽高 + dim + DPI` 在 ThreadPool 中一次性烘焙 `Format32bppPArgb` 的 1:1 背景，将 Cover、0.86 压暗、三向羽化与暗度遮罩全部合成；命中后仅 `DrawImageUnscaled` 一次。切换、缩放、调暗时后台重建并通过 `PaintGate` 原子发布，旧 Bitmap 及时释放。
- 切页与绘制只读内存缓存位图；`Paint*` 路径不执行任何文件读写，也不做大图缩放、渐变创建或 ColorMatrix 叠加。合成缓存尚未就绪时只铺主题底色，后台完成后通过事件立即刷新。
- 左侧「外观」调色板末尾新增 `+` 自定义皮肤圆点。点击打开原生深色配置浮层，可导入图片、切换已保存壁纸、删除当前壁纸并实时调节压暗浓度。
- 删除会清理原图、缩略图、背景缓存与配置项；配置损坏、文件缺失或缓存不可读时安全回退内置主题，不影响启动。
- 配置浮层按系统 DPI 缩放全部逻辑像素；150% 下顶部副标题与「已保存的壁纸」间距、压暗说明、离线说明与预览文字均完整显示。
- 原生 TrackBar 替换为自绘深色细圆角滑轨；中文预览改为无边框 TextBox + 1px 暗灰描边容器，默认置顶显示前 4 行以上。
- 复制按钮精简为「复制中文 Prompt / 复制英文 Prompt」，平台适配信息移入 ToolTip；右侧只保留「删除当前 / 打开壁纸文件夹」。
- 导入默认显示名取原图片文件名（清理非法字符、重名追加序号）；已有配置中的名称原样读取。

## AI 专属背景图提示词

- 内置 4 套预设：赛博驾驶舱 / 暗夜公路、古风水墨 / 远山云海、极简几何 / 磨砂光影、温馨书房 / 深夜台灯。
- 「画面主题」与「主色调」关键词可直接编辑，中文预览实时更新。
- 所有模板固定写入为 KeyMouseStats 布局优化的构图约束：16:9 宽屏、主体位于右侧 60%、左侧 35% 留白避开导航栏、顶部 20% 暗调低对比留白衬托白色标题、景深虚化与低碎纹理避免干扰前景图表。
- 「复制中文 Prompt（即梦 / 豆包 / 可灵）」与「复制英文 Prompt（Midjourney / Flux）」一键写入剪贴板，成功或失败都有状态反馈。

## 验收

- `tests/CustomThemeTests.cs`：四种图片格式导入、默认命名与重名序号、缩略图/缓存尺寸、主色与强调色对比度、50%/85% 压暗差异、边缘羽化、内存绘制（删除源目录后仍可出图）、配置重载、删除清理、异步导入、非法格式拒绝、Prompt 约束与预设回退，以及 **2560×1440/150% 合成背景单帧中位数 <15 ms** 回归断言，共 147 项检查。
- `tests/CustomSkinRender.cs`：1072×724 九页离屏渲染 + 配置浮层 100% / 150% `DrawToBitmap` 截图，共 22 项检查；输出 `previews/custom-skin-page-*.png`、`previews/custom-skin-dialog-100.png` 与 `previews/custom-skin-dialog-150.png`。
- 性能回归实测：合成背景单帧中位数 **7.7 ms**（优化前背景管线 87.8 ms）；全帧 **29.9 ms**（优化前 111.3 ms，内置纯色基线 21.1 ms）。
- `build-clean.bat`、`test.bat` 全部 `EXIT=0`；清爽版 956,416 B（约 934.0 KiB），无新增 `/resource:`，托管资源 0。
- 版本号单一来源：`Version.cs`、程序集 File/ProductVersion、`CHANGELOG.md` 与本文件统一为 3.1.0 / 3.1.0.0。

## 兼容性

- 数据格式 v13 不变；`stats.txt` 仅保留原有 `art_theme` 行，自定义壁纸状态独立存放在 `themes/custom-themes.json`，旧版本读取时自动忽略。
- 自定义壁纸完全位于用户数据目录，不写入 EXE、不随安装包分发、不上传。
- 清爽版同样可使用本地壁纸；不引入任何第三方库或新的嵌入资源。
