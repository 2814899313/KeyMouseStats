# KeyMouseStats 1.6.0

## 下载体积

`KeyMouseStats.exe` 从 82.0 MiB 降到 22.6 MiB。做法是把 34 个不含透明像素的资源（六个主题的背景、立绘与组件）改为 JPEG q90 嵌入，7 个含透明像素的图标图集与 UI 物件保持 PNG。程序仍是单文件、双击即用，不需要额外资源包，也不改变安装方式。

转换逐张记录了误差：平均像素差 1.4/255、最大 3.0/255；201 张渲染对比图平均差 0.17/255，六个美术主题在 100% 与 150% 下均未发现可见差异。原 PNG 母版保留在 Git 历史中，需要重新编码时可以取回。

## 持续集成

`test.bat` 新增 `--logic-only`，跳过依赖交互式桌面会话的 RenderDashboard 与 ThemePerf，其余 19 个测试照常运行。构建与发布工作流现在都会先跑这 19 个测试：测试失败时既不产出产物，也不会发布版本。此前 CI 只构建、不测试，一个从 1.3.0 起就失败的渲染测试因此被忽略了两个版本。

发版时的期望版本改为从 `AssemblyInfo.cs` 读取，不再需要手改工作流里的版本号。

数据格式仍为 v10，不迁移或改写历史统计。
