# KeyMouseStats 1.8.0

这一版加的是**互动性**:面板开始回应你的操作——点得下去、走得回来、键盘也能用;以及**数据面板动画**:数字和图表不再瞬间跳变,而是走过去。两件事都受同一条约束支配,下面先说这条约束,后面所有设计决定都由它推出来。

## 前提:动效和按键处理抢同一个线程

键盘钩子回调与界面在**同一个线程**上。挂在这个线程上的低层钩子如果超时,Windows 会把它摘掉——这是这个项目最不能碰的红线。所以动效在这里不是「好看就行」,而是每一帧都必须有界:

- **按住键时完全停表**。`HoldTracker.PendingCount > 0`(还有键没抬起)时直接不推进,帧绝不和钩子抢时间。
- **最小化、锁屏、会话断开、休眠时停表**。前者看 `WindowState`,后者统一走 `ActivityMonitor.Busy`。
- **按下一次重绘的实测耗时决定下一帧间隔**(`Motion.FrameInterval`:实测值 ×1.4,夹在 16–40 ms,即最快约 60 FPS、最慢 25 FPS)。超过 33 ms 的单帧算超预算,超过 100 ms 记进 `ui-stalls.log`。
- **没有动效时完全停表**,不产生任何额外重绘。

新的 `Motion.cs` 是这套东西的唯一入口。时间按**单调时钟插值**推进,不按帧计数:WinForms 定时器精度约 15.6 ms 且会抖动,数帧会让动画时长随负载漂移;按真实时间推进也让测试可以用假时钟确定性地推进。

## 三档动效,可以跟随系统

- **关闭 / 精简 / 完整**三档,入口在小部件右键菜单「外观 / 动效」。默认**完整**。
- **精简**档把每个通道的时长压到 120 ms 以内,并且不允许页面级动效(`AllowsPageMotion` 只在完整档为真)。
- **跟随系统「减少动态效果」**默认开启,读的是 `SystemParametersInfo(SPI_GETCLIENTAREAANIMATION, 0x1042)`。系统要求减少动态效果时,即使选的是完整也按精简运行;读不到这个设置时按「不要求」处理,不影响用户的选择。菜单里会显式标出当前是不是因为这个原因被降档。

档位与跟随开关落盘为新的可选行 `motion_v1=档位|跟随系统|全局快捷键`,旧数据文件没有这一行时保持当前设置,超出范围的档位回落到完整。

## 换页淡入:只做淡,不做位移

换页时内容区叠一层背景色薄幕渐隐(150 ms)。

**刻意不做位移**。内容一旦滑动,命中测试用的 chip 矩形就和眼睛看到的位置差最多十几毫秒的偏移——快速连点会点到隔壁。淡化只改 alpha、不改坐标,点击矩形始终和画面严格对齐,代价是少了一点「动感」,换来的是不会点错。

图表另有一条 280 ms 的**入场生长**通道:折线与数据点从基线升起,时段分布的柱子从零长高,排行条从零展开。换页和换筛选都会重开一次。悬停与坐标轴刻度始终用真实位置,不吃这条通道的缩放。

## 数字会追上去,而不是跳过去

小部件每 250 ms 才刷新一次,直接跳变很生硬。现在击键、点击、滚轮、鼠标路程与 APM 都按**半衰期追值**滚到新值(`Motion.Roll`,半衰期 160—200 ms)。

追值按**两次调用之间的真实时间**推进,所以帧率抖动不会改变收敛速度;首次调用直接落在目标上,不会从 0 开始爬。这也让「数值滚动」不用占一个动画通道——它自己就能告诉定时器还要不要继续出帧。

**离屏渲染不动效**。`Motion.Live` 由窗口在每次绘制时按 `Visible` 置位:测试截图、离屏渲染时数值直接落在目标值上,画面保持确定性,回归用例才能逐像素比较。

## 目标达成:一次庆祝

小部件的目标提醒触发时(`Wellbeing.GoalMessage` 返回文案),播一次 **900 ms** 的庆祝:三层由内向外扩散的**光晕环**加一枚**贴纸弹入**。前 55% 弹入、后 45% 淡出;光晕是描边不是位图,贴纸不带 alpha——不为一次庆祝分配任何中间位图。

它是**一次性**的:播完就结束,不会自己重播。按住键或锁屏时由 `Motion.Paused` 停住。

## 键盘也能用

面板不再是纯鼠标界面:

- **Tab / Shift+Tab** 在当前页的筛选项之间移动,选中的 chip 画一圈焦点环;**Enter / 空格** 激活它。
- **左右方向键**翻页,到头回绕。原有的 1—6 数字键切页保持不动。
- **Ctrl+C** 复制:优先复制当前悬停元素的明细文字,没有悬停就复制本页提示(含当前筛选)。复制成功后在页脚显示 2.5 秒的「已复制」。
- **Esc / Backspace** 返回上一层,没有上一层时 Esc 才关闭面板。左栏「快捷操作」把这些键位都列了出来。

## 点得下去:下钻与面包屑

- **总览页八张数字卡可以点**,打开对应报告页的今天区间:输入习惯、鼠标动作(第 8 页)、区间回顾(第 11 页)、使用节奏(第 3 页)各归其位。
- **键盘热力图可以点某个键帽下钻**:三格统计从全局切换为该键的数据——次数口径给「该键击键 / 占全部 / 本键排位」,按住时长口径给「该键累计 / 该键平均 / 该键最长」;选中的键帽加一圈描边。点空白处或按 Esc 回到全部按键。
- 下钻后标题行出现**面包屑**(`主题 / 页面 / 键位 · Esc 返回`),说明自己在哪一层。
- 换页会清掉面包屑与选中键位——换页就是离开原来那一层。
- 热力图换口径或换区间时,旧键位板留着做一次 200 ms 的**交叉淡入**。只保留一张旧板,不做逐帧重建,所以动画期间不会重复解码或反复分配位图;动画跑完立刻释放。

## 应用对比

应用页每行多了「对比」chip:

- 最多选**两个**;选中的行左侧加一条高亮。再点同一个应用取消;**选第三个时替换掉最早选的那个**,而不是被拒绝。
- 选满两个后,页脚提示行换成**并排对比**:击键、点击、滚轮,以及(有观测时)时长,并列给出两侧数值;击键后面附一个倍数 `(×N)`。文案严格卡在「清除对比」chip 左侧,不压到 chip 上。
- **时长这一项只在至少一侧有活跃时长观测时才出现**。老数据的应用活跃时长为 0,显示「0 秒 / 0 秒」只是噪音。
- 一个「清除对比」chip 清空选择;只选了一个时,页脚提示「再选一个应用即可对比」。

## 跨报告图例筛选

第 7 页(会话应用)的堆叠条图例可以点:点一下隐藏该系列,再点一下显示。

隐藏后堆叠条按**可见系列的合计重新归一化**——一行的总宽还是满的,只比较剩下的那几个系列。**永远不会把系列全关掉**:如果隐藏后只剩 0 个可见,会自动只保留刚点的那个。被隐藏的图例画成灰块加一道横线,并标出「(已隐藏)」;页脚同步显示「已隐藏 N 个系列」。

**只影响图**。明细表、悬停明细与导出都不受隐藏影响——筛选是阅读方式,不是数据口径。

## 按键配色绑按键,不绑名次

总览页的圆环图与「最常按键 Top 5」此前按**下标**取色。那等于用颜色把排名又编码了一遍,而排名已经由位置、条长和右侧数字表达了三遍;更麻烦的是颜色会随区间漂移——今天紫色是空格,切到本周紫色可能变成 I,「紫色 = 空格」这个记忆当场失效。

现在颜色绑在**按键显示名**上:空格永远是紫色,掉到第二也还是紫色,只是位置下移。位置说排名、颜色说身份,两者正交。

锚点表不是拍脑袋定的,是按真实数据排的:从 2026-09 的 64,345 次击键里取占比前 12 的键安排槽位,让频率相近的键拿到距离足够远的颜色。其余键走稳定哈希——这里特意没用 `string.GetHashCode`,因为它不保证跨进程稳定,会让颜色每次启动都换一套。前十名之内不允许撞色,超过 10 个的名次才复用。

身份色共 10 个,其中 4 个由主题色混合而来,所以九套主题下都成立。

**热力图刻意不动。** 那里的颜色表示**强度**(这个键按得多不多),不是身份——低值冷蓝、高值橙红,颜色本身就是数据,按键身份由键帽字母和固定的物理布局表达。把它改成身份色,这张图就不再是热力图了。`KeyPalette` 因此只暴露按身份取色的入口,并有一条回归断言拦住「以后有人加一个按数值取色的接口」。

## 换主题不再硬切

换主题时用**旧主题的背景色**做一次 220 ms 的全窗交叉淡化。

刻意不重绘旧主题的美术层:主题图片缓存可能已经释放,而且重绘一整页正好是这个项目最贵的操作(150% 缩放下最重的页面 20 ms 以上)。一次全窗 alpha 填充在这个预算之内。首帧只记状态、不做淡化;遇到未知主题(取不到底色)也不做。

## 覆盖率的分母改了

这一项**改了 1.7.3 以来的口径**,单独说明:

- 覆盖率原来的分母是「区间内全部击键」。但 1.7.3 之前的日子根本没有按住时长这一维度,把它们算进分母,刚升级的用户会看到一个虚低的个位数覆盖率——那是口径问题,不是样本问题。
- 现在分母是**采集期内**的击键:从区间内第一个有按住时长数据的日子(含丢弃样本的日子)起算到今天。报告页脚会写明「覆盖率按采集期(MM.dd 起 N 天)的 X 次击键计算」。今天仍在进行中,同样计入。
- 区间内没有任何按住时长数据时,分母为 0,覆盖率显示 `--`,不猜。

## 数据管理新增「已归档月份」

数据管理对话框新增一张**已归档月份**表(新的在前):月份、天数、击键、累计按住、有键按下、丢弃。超期日折进月度归档后,按住时长就在这里看,不再需要翻报告页脚。没有归档时给出说明行——「超出保留期的日会先折进月度归档,再从这里查看,不会直接删除」。

## 工程

- 新增 `Motion.cs`(动效时间轴、档位、通道、重绘范围、追值)与 `tests/MotionTests.cs` 回归套件(**49 项检查**,全部用假时钟推进,不依赖真实帧率);`build.bat` / `build-clean.bat` / `test.bat` 的源文件列表加入 `Motion.cs`。
- 新增 `tests/TestDiagnostics.cs`:部分区域设置下控制台打不出中文异常(会输出「由于 Exception.ToString() 失败」),它把完整异常写进临时文件并打印路径,同时返回非零退出码;也可以按类型名反射直接重跑单个用例。
- 动效通道自己声明重绘范围,调用方据此局部 `Invalidate`;**绝不在动效运行时整窗重绘**。
- 回归覆盖:缓动、通道生命周期与重启、一次性庆祝不自己重播、局部重绘范围的并集与整窗降级、停表与清理、三档降级与跟随系统、帧间隔夹取、追值的半衰期收敛与停表、动效设置的解析 / 往返落盘 / 越界回落,以及换页淡入、图表入场、主题淡化、应用对比最多两个、图例筛选不允许全关、键盘下钻与键盘导航的关键帧渲染断言。

## 报告窗口刻意不动

这一版所有的动效都只落在**面板**(主面板、小部件、应用页、热力图、主题切换)。报告窗口(17 页、9 套主题)保持静态,这是有意的:

- 报告是**模态对话框**:打开就是为了读一张表或一张图,淡入淡出只是拖慢读数,不会帮助理解。
- 报告页正好是**最贵的绘制**(150% 缩放下最重的页 20 ms 以上)。给它加逐帧动效,等于把最贵的操作乘上帧数;而这条时间轴和低层键盘钩子共享线程,单帧预算不允许。
- 报告的交互是**滚动与筛选**,不是「点进去看」。它没有下钻层级,也就不需要面包屑或焦点环这套为面板设计的东西。
- 键盘导航、Ctrl+C 复制、下钻与面包屑这些新交互**都只做在面板上**,报告窗口没有跟进;报告仍以鼠标加滚动为主。这是这一版的范围边界,不是遗漏。

如果之后要给报告加入场,正确的做法是复用 `Motion.Start` 并把通道的重绘范围限在图表矩形内,而不是给整页加时间轴。

## 升级

直接覆盖 `KeyMouseStats.exe` 即可,数据格式仍为 v11(`motion_v1` 是新的可选行,旧版本读到会忽略),1.7.6 的数据文件原样可用。动效默认完整档;不想要就在小部件右键菜单里选「动效:关闭」。按住时长报告的覆盖率数字会因分母口径变化而上升,这不是数据变了。

## 注意

「按住时长趋势」页是 1.7.6 的,这一版没有改动它。
