# KeyMouseStats 3.4.4

字符内容页的数据源引导落地：把配套的上屏记录插件开源，并在页面里直接给出下载入口。

## 字符内容

- 新增 `rime/commit_logger/`：七列上屏记录器的**公开发行版**，随仓库一同开源。
  - `lua/commit_logger.lua` —— 记录器本体（`debug` 默认关闭，不会持续写调试文件）
  - `lua/commit_logger_filter.lua` —— 候选流观察器，补齐「候选序」列
  - `schema-patch-sample.yaml` —— 处理器 + 滤镜两份补丁（必须 `/+` 追加）
  - `install-commit-logger.ps1` —— 只装插件的一键脚本，改文件前先备份
  - `README.md` —— 小狼毫/雾凇拼音下载地址、三步安装、排错表、列契约
- 记录格式为 `时间点,字符数,明文,程序,方案,码长,候选序`，与页面解析口径完全一致。
  **注意**：早先私下分享的三列包（`时间点,汉字个数,汉字明文`）会被判为旧格式跳过，
  且它带的安装脚本不装滤镜，候选序会恒为 `-1` —— 请改用本仓库这一版。
- 字符内容页在**没有任何上屏数据**时，页脚给出三个可点入口：下载小狼毫 / 雾凇拼音 / 记录插件。
- 空状态文案从过时的三列改为七列契约，并说明需要「小狼毫 + 雾凇拼音 + 记录插件」三件套。

## 文档

- `docs/text-content.md` 补齐官方链接、一键安装（PowerShell 一行）与手动三步两种方式，
  以及两个必踩的坑（`rime.lua` 要追加不能覆盖；方案补丁必须 `/+` 而不是 `@last`）。

## 安装插件（一句话版）

下载本仓库，进入 `rime/commit_logger/`，然后：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-commit-logger.ps1
```

装完打几个字上屏，`%APPDATA%\Rime\commit_log.csv` 有增长即成功。

## 下载

- 完整版（单文件、资源内嵌）：`KeyMouseStats.exe`
- 清爽版（不含美术资源，`KeyMouseStats.Clean.exe`）：与完整版功能一致，体积约 1.1 MiB

两者版本号均为 `3.4.4.0`。
