# KeyMouseStats 2.1.0

2.1.0 新增正式主题「古剑奇谭 · 琴心剑魄」，同时把主题覆盖范围从页面背景扩展到完整交互语言。

## 琴心剑魄主题

- 九页九景：总览、趋势、时段、按键、应用、洞察、字符、日报与点击热区分别拥有独立的仙山、剑台、琴室、星仪和灵脉场景。
- 全界面覆盖：统计报告、桌面悬浮小组件、游戏 HUD、加载动画、按钮、卡片边饰、状态徽标与环图光环均有专属设计。
- 键盘热力：加入 16 枚透明键帽纹章，按键类别使用剑纹、琴弦、玉符等不同装饰；最高频键以金色剑魄强调。
- 图标系统：加入 16 枚古铜与灵玉材质的功能图标，用于导航、指标卡和主题化提示。
- 配色：深墨青承载信息层级，灵玉青负责实时与选中状态，古铜金负责强调，朱砂红只用于异常与高热值。

## 资源与性能

- 新增 13 项主题资源：9 张页面背景、1 张组件背景、1 张报告背景、2 张透明图集。
- 背景采用等比覆盖裁切，不拉伸人物、山势与器物。
- 图片继续异步解码；原图缓存仍限制在 96 MiB，切换主题会释放不再属于当前主题的资源。
- 新增 `GujianThemeTests` 与扩展后的 `ThemeLoadingTests`，覆盖九页、键盘、报告、HUD、缓存预算和动画帧预算。

## 升级

直接覆盖 `KeyMouseStats.exe`。2.1.0 没有改变统计数据格式，2.0.7 的历史记录、分类和设置会原样保留。
