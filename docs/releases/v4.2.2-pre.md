# 4.2.2-pre · 预发布构建

> 这是 v4 重写线的**预发布**构建，**不是**可替代 v3 的正式版。
> 版本号唯一来源：`Directory.Build.props`（4.2.2-pre）；v3 仍为 `Version.cs` 的 3.4.4。
> 标签 `v4.2.2-pre` 会由 `release-v4.yml` 自动标记为 prerelease。

## 本次发布包含

- **字符内容 · 数据源引导**：页面上屏记录插件的开源发行版与安装入口，与 v3.4.4 同源
  （`rime/commit_logger/`：记录器 + 候选流滤镜 + 方案补丁样本 + 一键安装脚本 + 文档）。
- 版本号 4.2.0 → **4.2.2-pre**（`Version` / `InformationalVersion` / `VersionPrefix` 三处同步）。

## 与上个标签的差异

上一个 v4 标签是 `v4.0.0-alpha.1`；此后分支上的提交只有一条
（`feat(text): 上屏记录插件开源 + 字符内容页安装引导`）。数量不代表完成度 ——
本标签主要用于**分发一次可运行的预发布构建**并固定版本号。

v4 重写的功能面（全页面一屏全览、动态紧凑降级、卡片局部分页、按键页子视图等）
见 `docs/releases/v4.0.0-beta.1.md` 与 `v4.0.0-beta.2.md`。

## 已知未关闭项

沿用 beta 线的结论：24h 对拍、真机 200% / 多屏、人工穿透 / 焦点与剪贴板验收
尚未全部关闭；这些项通过前不会发 v4 正式版。
