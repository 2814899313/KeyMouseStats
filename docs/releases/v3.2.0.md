# KeyMouseStats 3.2.0（阶段一）

## 分页面壁纸

- 9 个页面可独立绑定壁纸；未绑定页面自动继承全局默认皮肤。
- 配置写入 `themes/custom-themes.json` 的 `pageSkins`，旧配置可直接升级。
- 视口合成底板使用最多 3 张的 LRU 缓存，切页后台烘焙并复用脏区 Blit。
- 配置浮层新增「全局 + 9 页」作用域胶囊与「跟随全局」。

## 图标与徽章

- 四个可定制槽位：左上主徽章、右上主题浮标、侧栏导航图标、KPI 角标。
- 5 套纯矢量风格：默认、赛博仪表、古风印章、像素复古、星轨罗盘。
- 任意槽位可导入 PNG/JPG/BMP，支持保留透明、去纯黑底、去纯白底。
- 图标烘焙为 `Format32bppPArgb`，保存在 `themes/icons/`；绘制路径不读写文件。
- 支持独立搭配或一键应用到全部槽位。

## AI 图标提示词

- 3 套图标模板：扁平矢量徽章、霓虹赛博发光图标、国风朱砂印章图标。
- 1:1 构图、单一居中主体、粗轮廓高对比、24px 可读、纯黑背景便于抠图。
- 中英文 Prompt 一键复制。

## 配置浮层精修

- 880×790 一屏布局，关闭 `AutoScroll`；壁纸 → 图标 → AI 提示词三段式。
- 图标区左右并排，右侧 2×2 实时预览。
- 禁用按钮 `#68768A` 中性灰 + 深描边；深色自绘下拉框替代原生 ComboBox。
- 修复下拉菜单关闭时销毁 `ContextMenuStrip` 导致的 `ObjectDisposedException`，菜单改为复用并随控件释放。
- 中文预览 4 行；壁纸卡片优先可读文件名，缩略图 Cover 裁切。
