# 3.4.1 · 多键盘 / 多鼠标外设健康

## 这次更新

- **每把键盘独立**：RawInput 按 `hDevice` 识别设备，保留每把键盘自己的按键磨损、额定寿命、起始日期和别名。
- **每只鼠标独立**：同样按 `hDevice` 识别鼠标/触控板，左右微动、中/侧键、近 7 天点击与额定寿命分别保存。
- **旧数据不丢**：升级前的单键盘、单鼠标档案保留为 `legacy`，可在健康卡里一键归入当前设备。
- **健康页改为只读数据面板**：默认只展示设备名、最高磨损和进度；编辑、换新、设备信息按需展开。
- **「全部」看最高风险**：不再用总额定寿命稀释单设备百分比，直接显示最该关注的那把键盘/那只鼠标。

## 数据与兼容

- `stats.txt` 保持 `format=13`；新增 `keyboard_v1` / `keyboard_keys_v1`、`mouse_v1` / `mouse_buttons_v1` / `mouse_days_v1`。
- 主键盘 / 主鼠标继续镜像 `hardware_v1`、`wear_keys_v1`、`wear_mouse_v1`，旧版仍可读取。
- 不依赖第三方库，清爽版继续 0 内嵌托管资源、≤ 2 MiB。

`build-clean.bat`、`test.bat --rebuild` 与 `test.bat` 全部通过。
