# 4.0.0-beta.2 · 一屏全览版

> 这是 v4 重写第二个 beta，**不是**可替代 v3 的正式版。
> 24h 对拍、真机 200%/多屏、人工穿透/焦点与剪贴板验收尚未关闭；正式 4.0.0 需在这些项通过后再发。
> 版本号唯一来源：`Directory.Build.props`；v3 仍为 `Version.cs` 的 3.4.1。

## 相对 beta.1 的变化

- **全页面一屏全览**：9 个核心看板移除主画布外层 `ScrollViewer`，改为按视口比例分配的 Grid；100% / 125% / 150% DPI 与主流窗口高度下不出现主内容纵向滚动。
- **动态紧凑降级**：高度较矮时自动收紧图表高度、列表行数与卡片密度；图表、时间线、九宫格、键盘热力均按剩余空间重排，不溢出视口。
- **卡片内局部分页**：逐日明细、Top 小时、应用表、组合键、Top 采样格、字词/词组等长列表改为固定行数「上一页 / 下一页」，页面外框始终锁死在一屏内。
- **按键页子视图**：按 V3 拆为「统计 / 外设健康」；统计内再分「按键排行 / 组合键 / 全键热力」，排行与组合键局部分页，热力与磨损卡一屏容纳。
- **字符页子视图**：拆为「字词 / 图表 / 隐私」；图表 4 张/页，字词 24 个/页（紧凑 15 个/页），词组 12 条/页（紧凑 8 条/页），默认仍模糊显示。
- **视觉收口**：排行条按实际列宽归一，修复窄卡片内条形溢出数值的问题；分页按钮改为无底色的轻量箭头；应用分布环改为紧凑短标签，避免中心文字截断。
- **回归基线**：9 页整页 golden 重生成；原 Text/Keys 长页基线替换为 928×650 紧凑视口基线，验证短窗口下无溢出；基线总数仍为 45 张。

## 验收基线

- 950 项测试全绿：Core 187 / Input 191 / Storage 35 / Golden 531 / Architecture 6。
- 45 张运行时基线：9 页 + Hours 96/144/192 三档 DPI + Widget 4 模式 × 3 主题 + HUD/Toast/胶囊 + Text/Keys 紧凑视口 + 报表 5 页 + 整窗外壳/美术皮肤。
- `--bench-ui`：本机 150% 缩放、9 页强制重绘，4,118 帧，平均 **4.321 ms**，P95 4.812 ms，P99 **5.411 ms**，120 fps 未降级。
- `--selfcheck-ui`：主窗、Widget、FocusPill、HUD、Toast 全部通过；HUD `TRANSPARENT`、Widget/Pill/HUD/Toast `TOOLWINDOW`/`NOACTIVATE` 均符合预期。
- 完整清单与证据表见 [`docs/v4-acceptance.md`](../v4-acceptance.md)。

- 真机 200%/多屏跨屏、人工鼠标穿透/焦点、微信/QQ 剪贴板粘贴尚未验收。
- 88.6 MB 单文件首次启动解包/杀软扫描需要干净目录复测。
