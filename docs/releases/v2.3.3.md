# KeyMouseStats 2.3.3

2.3.3 把历史数据改成永久、按时间组织的存储。

## 新目录结构

```text
%APPDATA%\键鼠统计\
  stats.txt                 当前月与全局设置
  2026\
    2026-01.txt             2026 年 1 月的逐日完整记录
    2026-02.txt
  backup\                   旧快照备份
```

- 当前月仍写入 `stats.txt`，跨月时自动把上一月写入 `年/月.txt`。
- 每个月文件保存完整日记录，不再只保留月度汇总。
- 启动时会把旧 `stats.txt` 里所有逐日明细拆分迁移。
- 用户删除某个月文件后，后续启动和保存都不会重新创建它；`backup` 里的旧快照由用户自行决定是否保留。
- 默认保留期改为永久；旧版默认 365 天在迁移时切换为永久。

## 兼容性

`stats.txt` 升级为 v13；旧 v12 及更早文件照常读取。迁移前会先保留旧快照，拆分完成后 `stats.txt` 只保留当前月，历史月份从年目录合并加载。

## 已知边界

- 当前月仍在 `stats.txt`，尚未生成当月月文件；到下一个自然月会自动归档。
- 月度文件按完整日记录保存，点击位置明细仍按原有 30 天策略单独裁剪。
