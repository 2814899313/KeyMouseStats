# KeyMouseStats 2.2.0

2.2.0 重构了统计报告，并把应用类深度分析迁移到主面板，统计报告最终保留 5 个页面。

## 输入习惯

- 页面高度固定；说明改到右侧无边框抽屉，打开时背景轻微模糊，不再把正文向下挤动。
- 「个人习惯基线」以过去 30 天中位数 P50、P90 为参照，颜色条带 0 / P50 / P90 锚点。
- 六项指标卡负责速读，底层表格默认收起，展开后补充历史最高、较昨日环比与计算定义。
- 顶部操作区统一为导出、在面板中查看、复制与刷新。

## 实时状态

- 折线改为平滑面积流，加入渐变填充、水平网格和右侧呼吸采样点。
- 图表标题改为「实时 APM 趋势 (近 5 分钟)」，右侧用胶囊展示窗口峰值；采样口径收进 ⓘ。
- 当前 APM 使用 36px 主数值，并显示活跃 / 空闲状态；历史峰值补充「创于 yyyy.MM.dd」。
- 明细表默认收起，主图下方补充实时键盘 / 鼠标负载和高频组合键。

## 保留的深度分析页

- 鼠标动作：移动方向与距离描述。
- 分布：区间内的逐日、段长和单应用时长箱线分布。
- 按住时长趋势：累计按住与有键按下的墙钟时间。

## 统计报告:入口退役

统计报告不再作为独立窗口维护，剩余能力已迁入主面板：

- 输入习惯、实时状态：总览卡片详情
- 分布：趋势页「分布」入口
- 鼠标动作：点击热区页「鼠标动作」入口
- 按住时长趋势：按键排行「按住趋势」入口
- 应用时段、应用操作、会话应用：应用统计行详情

旧的报告导航、报告入口和「在报告中查看」按钮已移除；日常分析统一在主面板完成。

## 主面板新增

- 总览的击键与有效使用时长卡片下加入过去 30 天 P50 / P90 基线。
- 趋势增加「对比上期」开关，图表右上角显示当前区间相对上一等长区间的均值变化。
- 时段分布增加「连续段强度」视图，段高与颜色表示输入强度，并附当前时间游标和专注段分布。
- 组合键排行补充快捷键估算节省提示，明确是假设模型，不计入有效使用时长。
- 应用统计支持点击应用行打开详情：应用 × 时段、操作构成、最近会话归因；类别卡只展示有数据的分类，未分类提供「去分类」入口。

## 升级

直接覆盖 `KeyMouseStats.exe`。2.2.0 没有改变统计数据格式，2.1.0 / 2.0.7 的历史记录、分类和设置会原样保留。
