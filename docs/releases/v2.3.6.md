# KeyMouseStats 2.3.6

2.3.6 让字符内容页只读取完整格式的 Rime 记录，并加入效率和应用视图。

## 完整格式

产品模式只接收：

```csv
时间点,字符数,明文,程序,方案,码长,候选序
```

要求程序、方案、码长、候选序都存在。旧三列、空候选序、缺程序或码长的记录会跳过并在页脚显示「已跳过 N 条旧格式」。

旧 `commit_log.csv` 可备份为 `commit_log.incomplete-<时间>.csv`；KMS 不会读取这个备份文件。

## 效率视图

字符页右侧新增「效率」：

- 首选率 = 候选序 0 / 有效候选序；
- 翻页率 = 候选序 >0 / 有效候选序；
- 候选覆盖率；
- 平均码长 = Σ码长 / Σ汉字数，只计 normal / mixed。

没有完整候选序或码长时显示 `—`，不回填、不猜 0。

## 应用视图

字符页左下新增「应用」标签：

- 按前台程序聚合输出字数、上屏次数；
- 每个应用显示高频字符；
- 使用友好应用名，不显示窗口标题。

## 兼容性

数据格式未改变。旧 Rime 记录保留归档，产品页只统计新完整采集期。
