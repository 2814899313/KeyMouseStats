# KeyMouseStats 2.0.6

这一版换外观:主题列表里的「苔原森林」换成「奥日 · 灵光森林」,程序图标也一并换新。

## 新主题:奥日 · 灵光森林

- **8 个主页面各用一张独立场景**:灵光森林、先祖之树、月下深池、灵木根系……不复用同一张背景;桌面悬浮组件、统计报告、游戏 HUD 也各有独立背景,不是从主页面裁出来的。
- **键盘热力图**:16 种灵纹键帽装饰,最高频键显示「灵光之键」;最高频键的描边换成金色灵光。
- **界面语言**:导航图标、指标卡符号、按钮、进度环、载入动画都换成灵光 / 藤蔓 / 符文;主题徽章用专属的灵纹符号。
- **主题 id 仍是 2**:原来选中「苔原森林」的用户升级后会直接看到新主题,设置不需要迁移;想换浅色主题照常点色点。
- **资源编码沿用 1.6.0 的约定**:10 张不透明背景 / 组件转成 JPEG q90,2 张透明图集(4×4 图标、键帽纹样)保留 PNG。嵌入后约 7.6 MiB,解码原图约 72 MiB,在 96 MiB 预算内。
- 正式版主题数仍是 **12 套**,主题选择器的布局和色点数量不变。

## 新图标

- 程序图标换成美术给的「K」标:深蓝圆角底、青白 K、橙色灵光点。
- 托盘图标、窗口标题栏图标与 exe 文件图标统一;ICO 含 16/20/24/32/40/48/64/96/128/256 十档,Windows 按 DPI 取帧。
- 图标素材与生成脚本入库:`assets/app-icon-source.png`、`tools/make_app_icon.py`,以后要改图标可以直接重跑。
- 清爽版不嵌入托管资源(CI 有校验),只带 exe 文件图标;托盘图标回退到文件图标,体积仍在 2 MiB 以内。

## 清理

- 之前作为独立「奥日定制版」的构建脚手架(`build-ori.bat`、`test-ori.bat`、定制版说明)已经并入正式版并删除,不再产出独立的 `KeyMouseStats-Ori-Custom.exe`。
- 删掉过期的 `render-failure.txt`(2.0.5 修好导航点击之前留下的渲染报错)。

## 回归

- 新增 `tests/OriThemeTests`:校验主题 id 2、12 套主题数量、12 张资源登记、8 页离屏渲染、键盘热力图 / 报告 / HUD / 图集渲染与资源预算。
- `ThemeLoadingTests` 把奥日主题纳入加载与动效帧预算;`ThemeOwnershipTests` 把奥日 12 张资源纳入常驻与预算检查;`RenderDashboard` 增加奥日主题的资源等待与预览输出。

## 升级

直接覆盖 exe,数据格式不变。主题设置里原来选中的「苔原森林」会自动显示为「奥日 · 灵光森林」。
