# 键鼠统计 1.3.0 正式版

一个悬浮在桌面上的小组件,实时统计**键盘击键**和**鼠标使用**(点击、滚轮、移动距离),并内置一个**详细数据分析面板**(趋势图 / 时段分布 / 按键排行)。

![碧血丹心主题总览](docs/screenshots/wuxia-overview.png)

[下载最新版本](../../releases/latest) · [查看更新日志](CHANGELOG.md) · [主题资源规范](THEME_RESOURCES.md)

- 单个 exe,使用 Windows 自带的 .NET Framework 编译,**无需安装任何运行环境**
- 使用低级钩子与 Raw Input；主题图片后台加载并采用有界缓存，内存占用随主题、窗口尺寸与历史数据变化
- 数据最多保留 **365 天**历史,支持导出 CSV
- 所有统计均在本机完成，不记录实际输入内容，也不上传个人数据

## 详细数据分析面板

面板采用侧边导航、主题化指标卡和统一图表配色，支持导航与筛选按钮悬停反馈。窗口按屏幕工作区适配大小，字体与图表随缩放同步调整。

侧栏底部提供 5 套可切换美术主题：**午夜蓝**（原版深色）、**奶油手账**（暖纸色、细边框）、**苔原森林**（苔绿、柔和大圆角）、**霓虹夜航**（紫色网格、青色高光）、**蓝图工坊**（浅蓝网格、直角卡片）。点击色卡立即应用，悬浮小组件同步换色，重启后记住选择。主题覆盖所有统计页面、图表和热力格；系统设置弹窗保留 Windows 原生样式。

双击小组件、托盘菜单选"详细统计面板"、再次启动程序,或在面板中按 `1-6` 切换页面。共六个页面:

### ① 总览
- 八张指标卡:今日击键 / 点击 / 滚轮 / 移动距离、**有效使用时长 / 连续使用段**，以及**实时速率**(最近 60 秒的每分钟击键与点击数)
- 点击“有效使用时长”设置空闲阈值；点击“连续使用段”查看今日各段的开始、截至采样时间和持续时长
- 鼠标按键分布环图(累计):左键 / 右键 / 中键 / 侧键 的次数与占比
- 最常按键 Top 5(累计)
- 底部"洞察"条:最常用按键、高峰时段、日均击键

### ② 趋势
- 最近 **14 / 30 天**每日折线图,可切换 击键 / 点击 / 滚轮 / 移动距离 四种指标
- 悬停显示单日数值;虚线为期间平均;今日数据点高亮
- 底部汇总:期间合计 / 日均 / 最高单日 / 较昨日增减
- 日趋势新增 7 日移动均线（主题青色虚线）：需连续 7 个有记录日期；缺失日不补零，不足 7 日时留断点。所选指标的均线与原折线共同决定纵轴范围。
- 新增 **按天 / 按小时** 切换。小时模式支持击键、点击、活跃分钟三项，点击日期选择最近 365 天内任意一天，也可前一天 / 后一天 / 回今天。
- 小时折线固定展示 00–23 点，悬停显示小时区间和数值；当前小时标记累计中，未来小时与缺失日期留空。下方显示合计、已过小时均值（不含当前未满小时）、最高小时量和最忙时段。均值与计数仅基于已有采集数据，并不表示每小时都完整监测。
- 小时模式增加 **击键/秒、点击/分**，用该小时 ActiveHours 归一化；活跃秒数为零时留空，不绘制无穷大或假零值。密度的第一张卡显示全日计数 / 全日活跃时间，第二张为已过、具有活跃记录小时的密度算术平均。
- 小时模式 CSV 导出当前日期、当前指标的 24 小时明细，缺失项为空并附状态。滚轮和鼠标路程没有历史小时桶，保留在按天模式中；不从每日总量反推小时分布。

### ③ 时段分布
- 24 小时热力条 + 各时段柱状图(全部历史),可切换击键 / 点击
- 悬停查看某小时的数量
- 统计卡:最忙时段 / 活跃小时数 / 峰值 / 深夜(0-6 点)占比
- “活跃时长”选项按小时显示活跃分钟数，可切换今日 / 近 90 天；“有活动时段”表示有记录的小时格数量，并非有效使用小时数

### ④ 按键排行
- Top 10 最常按键排行(可切换 今日 / 近 90 天,左右 Shift/Ctrl/Alt 自动合并)
- 按键概况:不同按键数 / 总击键 / 最常用 / 前三占比 / 记录天数 / 键鼠比
- 新增 **单键 / 组合键** 切换；组合键显示 Top 10、组合种类、动作次数、最常用组合和前三占比，可选择今日 / 近 90 天。组合键视图的 CSV 导出所选范围内的全部组合明细。

#### 组合键计数规则

- 支持 Ctrl、Alt、Shift、Win 与普通键组合，例如 `Ctrl+C`、`Alt+Tab`、`Win+Shift+S`。普通键第一次按下时计一次；长按自动重复不重复计数，普通键释放后重新按下才计下一次。一直按着 Ctrl，依次按 C、V 会分别计一次。
- 左右修饰键内部独立维护，展示时合并；同时按住左右 Ctrl，松开其中一个不会丢失另一个。仅按修饰键不计组合；Shift+字母也属于组合。
- 修饰键顺序统一为 Ctrl、Alt、Win、Shift；持久化标识例如 `ctrl_c`、`win_shift_s`，特殊按键使用虚拟键码标识。组合次数保存在每日 `ComboCounts`，数据文件每项为 `combo=标识:次数`。
- 单键按“按下—释放”周期计数：首次按下计 1 次，长按产生的系统自动重复不增加总击键、按键排行、小时击键、应用归因和实时速率；松开后再次按下再计一次。Ctrl / Shift / Alt / Win 自身也按此规则计数，左右键分别跟踪。输入事件仍正常传给系统和其他应用，不影响长按输入、退格或游戏操作。
- 组合键计数与单键计数并列，不额外增加总击键；例如 Ctrl+C 含 Ctrl 和 C 两次单键按下、一次组合动作。旧版本已经累计的自动重复次数无法从总数里准确拆除，历史数据保持原样。
- 按下状态由 `WM_KEYDOWN` / `WM_SYSKEYDOWN` 和 `WM_KEYUP` / `WM_SYSKEYUP` 跟踪；启动时在钩子外读取已按住的键，锁屏、会话切换和休眠时清理状态。不会用固定超时拆开仍然按住的组合。
- 统计的是观察到的按键动作，不推断应用是否执行了复制等命令。部分键盘布局的 AltGr 可能表现为 Ctrl+Alt；安全桌面等未送达钩子的按键无法统计。
- 旧版数据无法还原组合顺序，组合统计从新版启动后开始。

### ⑤ 应用统计

- **手动分类快捷入口**：点击每行右侧“手动分类”，直接选择编程、办公、游戏、视频、其他或未分类，即时保存并重新汇总历史记录。“按应用”视图设置应用默认用途，“按窗口”视图设置该精确标题；应用默认不会清除已有窗口 / 关键词规则。菜单可恢复自动判断，也可打开高级规则设置标题关键词和适用范围。

- 每次击键、鼠标按键点击和滚轮事件，捕获当时的前台窗口，按 **进程路径 + 窗口标题** 累计次数。可以切换今日 / 近 7 天 / 近 90 天，以及按应用 / 按窗口汇总。相同进程路径和相同标题合并；不同标题分开。
- 顶部显示编程、办公、游戏、视频、其他、未分类的击键次数及占比；列表分别展示击键、点击、滚轮，支持翻页。浏览器内不同标题的网页可分别查看。
- 自动分类覆盖常见编辑器、终端、办公软件、游戏、播放器和系统工具。WPS / Office / OpenSquilla / 普通 ChatGPT 默认归办公，Codex 的 `OpenAI.Codex_...` 安装路径即使程序名为 `ChatGPT.exe` 也归编程，资源管理器和本工具归其他。常见浏览器标题以 GitHub / Stack Overflow / Microsoft Learn / MDN 等站点名结尾时推测为编程，以 YouTube / 哔哩哔哩等结尾时推测为视频；明确标注“站点推测”，不根据孤立的“代码”“视频”等泛词强制分类。
- 通用 AI 助手默认“办公”只是用途预设，可按实际用法调整；[OpenSquilla 官方介绍](https://www.opensquilla.ai/zh/)将其定位为通用 Agent。点击每行的 **分类…**，可设置应用默认用途、**此应用标题包含关键词**，或精确窗口规则。例如在浏览器 / AI 助手里把项目名归为编程，标题变化后仍匹配。关键词不区分大小写，只作用于当前应用路径；保存前预览匹配的历史标题与击键量，关键词下拉可编辑已有规则。
- 优先级：**精确窗口 > 标题关键词 > 应用默认 > 站点推测 / 应用预设**。多个关键词同时命中时采用最长的，同长按字典序确定。设置应用默认用途保留更细的规则；选择“不设此规则 / 删除此规则”仅清除当前规则，恢复下一级判断。规则变更重算已有记录并作用于后续输入。
- 列表显示“窗口规则 / 关键词规则 / 应用规则 / 站点推测 / 应用预设”等分类来源，悬停分类查看具体依据。“只看待标注”切换到窗口视图并过滤未分类记录，排除无法补查的旧数据。分类仍是手动标注或推测，不识别网页正文、游戏状态或实际观看时长。
- 本页的 **导出 CSV** 导出所选日期范围内的逐日窗口明细，包含应用、标题、路径、分类、三项次数、分类来源及依据。标题中的逗号、引号、换行经过转义，并处理电子表格公式前缀。
- 旧版记录无法补查当时的前台应用，显示在“旧数据 / 未归因”，计入未分类；无法识别的窗口同样保留次数。切换窗口的那次点击归于钩子捕获时的前台窗口，可能仍是切换前的窗口。
- 标题与进程路径保存在本地 `stats.txt`，随每日记录保留最近 365 天；不保存输入文本。单个标题最多捕获 512 个字符，单日最多保存 2000 个不同标题，超出后的新标题合并到一个未分类条目，次数不丢失。
- 归因采用 `GetForegroundWindow`、`GetWindowThreadProcessId`、`GetWindowText` 和 `QueryFullProcessImageName`；进程路径使用短期缓存，避免每次事件都查询。没有权限或窗口切换中的识别失败会回退为未分类，无需管理员权限。
- 滚轮与点击现在分别计数；旧版小时点击/实时点击速率把滚轮混入的问题已修正，新记录不再混算，旧的小时数据无法追溯拆分。

### ⑥ 使用洞察

- **年度日历**：过去 365 天的 GitHub 风格热力格，可切换活跃时长 / 击键次数。绿色浓度按当前范围最大值缩放，悬停显示日期数值，点击进入当天时间轴。无记录与已记录的零值分开显示，今日仍在累计；旧版已清理的日期无法补回。
- **会话时间轴**：默认今天，可逐日切换。全天按位置展示活跃段（绿）、已观测空闲（橙）和无区间记录部分（底色）；悬停查看秒级起止时间及有效时长，下面有分页明细。短时段最小显示 1 像素。
- **平均活跃段 / 最长活跃段**：根据当天 Sessions 的有效秒数计算。平均值是各段秒数之和除以段数，空数据不显示为零。活跃包含阈值内停顿，不等于专注；会话没有用途时间归因，因此不推断工作 / 游戏。
- **长空档检测**：显示已观测、至少 15 分钟的空闲段数量和最长 Top 3。新版开始保存 `idle_period` 起止和秒数；旧版只有 `IdleSeconds` 总量，不能反推发生时间。锁屏、休眠、退出和采样中断不填为空闲。
- **七日节奏**：7 天 × 24 小时活跃热力矩阵，色阶固定对应 0–60 分钟；悬停查看每小时已采集的活跃分钟，点击日期行进入时间轴。展示覆盖天数、最活跃日期、累计最忙时段；今日未结束、缺失采样可能影响比较，不能凭一周推断长期星期偏好。
- “时段分布”的活跃视图新增 **七日活跃对比** 入口。本页 CSV 导出所选日期（默认今天）的活跃和已观测空闲区间。

## 统计报告与个人基准

## 鼠标实际路程与 DPI

- 右键小组件或托盘 → **鼠标 DPI / 距离校准**，填写鼠标驱动中当前的 DPI 后保存。首次使用不假定 DPI，输入框中的 800 仅为示例，保存后才开始累计米数。
- 新路程通过 Raw Input 相对移动量计算：`累计 sqrt(dx² + dy²) / 当前 DPI × 0.0254`，以米保存，界面自动显示 cm / m / km。这里的 dx、dy 是鼠标原始计数，不是屏幕像素。
- 屏幕分辨率、缩放和 Windows 指针速度不参与此换算。光标到达屏幕边缘后，仍可以累计鼠标的相对移动。
- 实测校准：使用尺子，设置测量长度（默认 10 cm），让设置窗口保持前台，鼠标对齐起点，按 **F8**，沿直线单向移动指定长度，到达终点按 **F9**，再保存结果。校准期间暂停米数累计；失去焦点会取消本次校准。
- 鼠标路程是估算值。支持相对移动鼠标，忽略数位板等设备的绝对坐标输入。当前使用一个全局 DPI；切换鼠标或硬件 DPI 档位后需要手动更新设置，同时使用不同 DPI 的鼠标不适合此设置。
- DPI 修改仅影响后续移动，历史米数不会重新换算。旧版 `move` / `total_move` 仍保存为**光标路程（px）**，新米数独立存入 `move_m` / `total_move_m`，不会把旧像素误当米。只有旧数据的日期，其鼠标米数为 0，表示当时没有记录该指标。
- CSV 分别导出鼠标路程（m）和光标路程（px）；设置窗口可查看累计光标路程。原始逐次移动轨迹不写入磁盘。
- 保存时原子替换数据文件，并将上一版保存为 `stats.txt.bak`。首次升级后请使用新程序，旧程序无法保留新增字段。

## 空闲检测与连续使用段

- 通过 `GetLastInputInfo` 读取当前 Windows 会话最后一次输入的时间。默认最近 **60 秒**内有输入视为活跃，阈值可在总览时长卡或托盘“空闲阈值 / 活跃时长”中设置（10–3600 秒）。
- 有效使用时长是基于输入的估算：短暂停顿也计入，最后一次输入后最多再计入一个阈值的时间。单纯观看视频且长期没有输入会判为空闲。
- 约每秒采样，以实际经过的时间累计活跃/空闲秒数，而非每次 250 ms 界面刷新都增加一秒。超过阈值结束连续使用段，再次输入后开始新段。使用段不按应用切换拆分。
- 锁屏、会话断开、休眠会中断计时。超过 5 秒的采样中断、明显系统时间跳变不会补计；恢复后以新观测开始，避免把未观测到的整段时间算作使用。程序未运行期间也不补算。
- 跨小时按比例拆分时长；跨午夜拆为两天各自的使用段。退出、重启、重置统计或修改阈值会结束当前段；已保存的旧段不会与重启后的新段拼接。
- 标准按日 CSV 增加有效使用秒数、观测空闲秒数和连续使用段数。“观测空闲”仅包括程序正常采样时的空闲，不包含锁屏、休眠或程序未运行的整天剩余时间。
- 活跃时间和使用段仅从新版开始记录。旧版每日计数保留，无法从历史击键数还原活动时长；对应新字段默认为 0。
- 相关接口：[GetLastInputInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)。它提供当前会话的信息，不能代表其他 Windows 用户会话。

## 键盘热力与配列

- 键盘热力与七日节奏共用蓝 → 青 → 黄 → 橙 → 红的连续色带，数值线性映射，蓝色低值、红色高值。七日节奏固定以每小时 60 分钟为上限，键盘以当前范围、当前配列的最高次数为上限，图例标出对应数值。已观测零值使用中性灰，七日节奏中无记录或未来时段保留斜线标记；切换主题不会改变数值对应的色带。

- 入口：**按键排行 → 键盘热力**。支持今日、近 90 天，键帽颜色表示使用次数，悬停显示次数及其占全部击键的比例，适配现有五种主题。右上角选择全尺寸 ANSI 104、87 键、75%、65%、60% 示意布局，选择会保存。
- 自动模式通过 Windows Raw Input 枚举键盘，参考设备报告的总键数推荐配列。驱动报告值不保证等于实际键帽数；不明确、读取失败或多个配列冲突时回退到全尺寸并提示手动选择。换键盘后可在配列菜单点击“重新检测键盘”。参考：[RID_DEVICE_INFO_KEYBOARD](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-rid_device_info_keyboard)。
- 当前提供标准 ANSI 配列示意，紧凑键盘不同厂商的位置、ISO/JIS、分体键盘和自定义固件可能不同；不会声称精确识别型号。多把键盘的计数合并，尚未逐设备分开统计。Fn 一般由硬件处理，不把无法观测的 Fn 当成零次；60% / 65% 的左上角以 ` / Esc 合并展示常见固件层。
- 新版按扫描码和扩展位记录物理键，区分左右修饰键、主区与小键盘 Enter、数字区与方向区；长按仍只计一次。旧记录按虚拟键近似归位，不能还原旧 Enter 所属区域，也不能还原 NumLock 关闭时的物理位置。界面显示旧记录数量与当前配列覆盖数；不会把旧 Enter 次数复制到两个 Enter 上。
- `physical_keys` 保存物理键位计数，`physical_vks` 保存这些事件对应的虚拟键计数，用于从旧数据中扣除已按物理键归位的部分。CSV 按扫描码导出，含次数、占比、旧记录数量；历史中无法归位的键仍保留在单键排行。

### 低配置电脑性能与主题载入

主题原图按主题注册表后台串行预加载，保留原始分辨率；当前主题原图不因翻页被驱逐，切换主题后释放旧资源。原图预留与常驻预算 96 MiB（不含解码临时内存和其他程序数据）。背景使用独立的当前页预缩放缓冲，上限 36 MiB；小图标另用 4 MiB / 128 项缓存。快速换主题通过代次隔离丢弃过期结果。键盘内同一键位移动不重复绘制，悬停刷新按绘制耗时调节，最小化时暂停统计面板刷新。

首次读取素材时，页脚显示对应主题的星光、战术雷达、心电或方块动画；只重绘动画区域，完成后恢复原有页脚提示，不人为延长等待时间。异常图片使用原有底色兜底。图片解码异常及未处理的进程异常记录至 `%LocalAppData%\KeyMouseStats\diagnostics.log`（约 1 MiB 轮换），便于排查其他电脑上的退出问题。日志不能覆盖系统强制结束或所有原生崩溃。

`tests/ThemeLoadingTests.cs` 使用独立示例数据验证五个美术主题、六页、100%/150% 比例的反复加载、缓存上限、绘制耗时与缺失图片兜底；不读取或写入真实统计数据。
