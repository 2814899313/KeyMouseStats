# 键鼠统计 · 报告设计原型

日报 / 周报 / 月报的纯 HTML 视觉稿。**没有接入程序**，所有数字都是样例数据。

## 打开方式

直接双击 `index.html` 即可；如果想用本地服务：

```bat
cd design\report-redesign
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 可以试的交互

- 左侧 `01 / 02 / 03` 切换日报、周报、月报；也可以按键盘 `1` `2` `3`。
- 右上角 `午夜 / 纸张` 切换深色和浅色主题。
- 图表、应用行、日历格子都有悬停提示。
- 右上角「导出报告」和日期步进器是原型占位，点击会给出提示。
- 直接打开某一份报告：
  `index.html?report=weekly&theme=light`

## 设计说明

- **一张纸，而不是一堆卡片**：整份报告放在同一张 sheet 上，用细分隔线和留白分区，减少旧版五张卡片并排的「仪表盘感」。
- **每个时间尺度一种主色**：日报琥珀、周报薄荷、月报紫罗兰；浅色主题自动换成对应的深色强调色。
- **数字用衬线体，正文用无衬线体**：大数字和标题里的关键数字更有一点「刊物」气质。
- **日报讲一天的故事**：先给一句人话摘要和四个关键数字，再用 24 小时脉搏图 + 会话时间带解释这一天是怎么过的，最后才是应用、习惯、文字和效率侧写。
- **周报讲节奏**：一周柱状轮廓 + 7 天趋势 + 上午/下午/晚上分布 + 周末降速。
- **月报讲形状**：日历热力图 + 30 天轨迹 + 四周拆分 + 月度之最。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 三份报告的 HTML 结构 |
| `styles.css` | 设计变量、布局、深色/浅色主题、响应式 |
| `app.js` | 图表、切换、主题、悬停提示，无依赖 |
| `preview-*.png` | 深色/浅色静态预览图，方便快速对比 |

## 原生导出（已接）

日报 / 周报 / 月报都已接上原生渲染。点日报页的「生成战报长图」会弹出小菜单：

- 日报长图：当前选中日
- 周报长图：以当前选中日为最后一天的最近 7 天
- 月报长图：当前选中日所在月份（当月统计到今天）

统一规则：

- 固定午夜深色，逻辑宽 1440，输出 3×（4320px 宽）
- 只画报告纸，不含左侧导航和顶栏
- 日报琥珀、周报薄荷、月报紫罗兰
- 保存到日报目录：`%APPDATA%\键鼠统计\日报\`
  - `yyyy-MM-dd-日报.png`
  - `yyyy-MM-dd-周报.png`
  - `yyyy-MM-月报.png`
- 同时尽量复制到剪贴板；打码开关对应用名、高频字/词和注脚生效

原生效果图：`previews/daily-poster.png`、`previews/weekly-poster.png`、`previews/monthly-poster.png`，以及 `previews/daily-poster-mask.png`。
